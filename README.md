## 🎨 Sobre o Projeto

Calculadora desenvolvida em **Flutter** com foco em design moderno, boa usabilidade e feedback tátil ao toque.

### 🌟 Destaques

- 🌓 **Modo Claro / Escuro (Light/Dark Mode):** Alternância instantânea no topo (Sol/Lua).
- 📜 **Histórico de Cálculos:** Painel deslizante para consultar operações anteriores.
- ⚡ **Micro-animação:** Efeito tátil de encolhimento (*scale down*) nos botões ao pressionar.
